# 0027. 문서의 명시적 분류 조작 지시는 미분류로 보낸다

## 결정
파일명·본문에서 알려진 지시 무시·분류 조작 패턴을 탐지하면 provider 호출 전에 미분류와 빈 인용문을 반환한다. 카테고리 설명은 0020을 유지하고 인용 원문 검사(0018)와 인젝션 평가를 분리한다.

## 이유
Qwen 평가에서 본문의 계약서 지정 지시를 따라 오분류했지만 그 지시가 원문에 있어 인용 검증을 통과했다. 원문 일치는 근거의 타당성이나 지시 추종 여부를 보장하지 않으며, 규칙 탐지도 우회·오탐 가능성이 있다.

## 버린 대안
- 인용 검증만 유지: 원문에 들어 있는 공격 문장은 통과한다.
- 프롬프트 경고만 강화: 기존의 지시 무시 경고도 Qwen이 따르지 않았다.
- 의심 문장만 삭제해 자동 분류: 삭제 범위를 잘못 정하면 문서 의미가 바뀌거나 남은 공격을 따른다.
- 별도 LLM으로 공격 판별: 추가 호출 비용과 같은 지시 추종 실패 가능성이 있어 이번 방어로 선택하지 않는다.
