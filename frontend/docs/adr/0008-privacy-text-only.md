# 0008. 원본은 로컬 OCR에만 전달하고 외부 분류에는 앞부분 텍스트만 보낸다

## 결정
원본 파일은 OCR을 위해 사용자 PC의 로컬 백엔드에만 전달하며 원본을 변경하지 않는다. OCR은 로컬 CPU에서 수행하고 결과 TXT·JSON은 backend/outputs/처리ID/원본이름.txt 및 .json에 저장해 재처리 결과도 보존한다. 외부 분류 서버에는 필요한 앞부분 텍스트만 보낸다.

## 이유
민감한 원본의 외부 전송을 막으면서 로컬 OCR 결과를 후속 처리에 활용하고, 처리별 폴더로 같은 이름의 결과가 덮어써지는 것을 방지한다.

## 버린 대안
- 외부 서버에 원본 파일 업로드: 민감한 문서가 사용자 PC 밖으로 나간다.
- 이미지를 멀티모달 LLM에 전송: 보안 위험과 비용이 크다.
- 전체 텍스트 전송: 비용과 전송량만 는다.
