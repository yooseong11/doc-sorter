# 0019. 카테고리 목록은 런타임 상태로 두고 요청 본문에 싣는다

## 결정
shared에는 기본 카테고리와 스키마 생성 함수만 두고, 분류에 쓰는 목록은 브라우저 런타임 상태에서 요청 본문에 실어 보낸다. 미분류는 편집 대상이 아니다.

## 이유
모듈 로드 시점에 굳는 picklist와 enum 때문에 사용자가 고친 카테고리로는 분류할 수 없고, 목록을 요청에 실으면 서버를 무상태로 둔 채 프리셋만 바꿔 다른 팀에 줄 수 있다(0001).

## 버린 대안
- 서버가 프리셋을 저장: 무상태 함수에 저장소가 생기고 화면과 서버 목록이 어긋날 수 있다.
- 고정 상수 유지: 사용자가 이름과 설명을 추가한다는 결정(0002)을 구현할 수 없다.
- 미분류도 편집 가능: 저장 폴더(0014)와 분류 실패 시 보낼 곳이 함께 무너진다.
