# 0015. 분류 근거 인용문을 화면까지 내려보낸다

## 결정
모델이 근거가 된 문장을 원문에서 120자 이내로 인용해 응답에 담고, 확인 화면이 그대로 보여준다. 기록표 CSV에는 남기지 않는다.

## 이유
왜 그 카테고리인지 화면에서 읽을 수 있어야 사용자가 오분류를 잡아낸다. 인용문은 이미 보낸 앞부분 텍스트에서 나오므로 0008이 정한 전송 범위는 그대로다.

## 버린 대안
- 모델이 요약한 사유: 원문에 없는 문장이라 진짜 근거인지 확인할 수 없다.
- 길이 상한 없음: 본문 문단이 통째로 응답에 실리고 확인 화면이 길어진다.
- CSV에 근거 열 추가(0006): 문서 본문 문장이 회사 폴더 파일에 복사되어 남는다.
