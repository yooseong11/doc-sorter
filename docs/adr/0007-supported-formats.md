# 0007. 읽을 수 있는 파일 형식

- 상태: 채택
- 날짜: 2026-09-17

## 결정
- 텍스트 PDF(pdfjs-dist, 지연 로드), DOCX(mammoth), HWPX(jszip) → 분류
- HWP, DOC, 이미지 → 미분류

## 이유
- 한국 회사라면 한글 파일은 빠질 수 없다.
- 옮기기(저장)는 형식과 상관없이 된다. 형식이 문제 되는 건 분류하려고 내용을 읽을 때뿐이다.
- 형식마다 텍스트를 꺼내는 난이도가 다르다. 텍스트 PDF·DOCX는 쉽고, HWPX는 ZIP + XML이라 보통이다. HWP는 바이너리라 JS 라이브러리가 드물고 완성도 편차가 크며, DOC는 브라우저에서 사실상 어렵다.
- PDF는 만든 방법에 따라 글자일 수도 이미지일 수도 있다. 한글·워드에서 저장하거나 홈택스·ERP에서 받은 PDF는 글자이고, 스캔·휴대폰 촬영본은 이미지다. 추출한 텍스트가 거의 비어 있으면 이미지 PDF로 보고 미분류로 보낸다.
- 읽지 못하는 파일도 미분류로 받아서 저장·기록은 똑같이 한다. 사용자를 버리지 않고 어려운 추출만 뒤로 미룰 수 있다.
- 형식별 추출기의 모양을 통일해 두면 HWP 지원을 나중에 함수 하나 추가로 끝낼 수 있다.
- PDF 워커가 gzip 약 375KB로 가장 커서, PDF가 올라왔을 때만 불러온다.

## 버린 대안
- OCR(tesseract.js 후보): 보류
- HWP 텍스트 추출: 보류
