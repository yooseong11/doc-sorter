# 0022. 파일은 카테고리를 id로 가리키고, 이름→id 변환은 클라이언트가 한다

## 결정
파일은 `categoryId`를 저장한다. 이름 변경은 따라가고, 삭제되면 미분류로 바꾼다. 같은 이름을 다시 추가해도 새 id다. AI가 돌려준 이름은 클라이언트가 응답을 받을 때 프리셋으로 id로 바꾸며, 없는 이름은 미분류로 보낸다.

## 이유
카테고리를 편집할 수 있게 되어(0019) 이름은 바뀌는 값이 됐고, 이름으로 가리키면 이름 변경과 삭제를 구별할 수 없다. 변환을 클라이언트에 두면 서버 계약(0016)을 바꾸지 않는다.

## 버린 대안
- 이름으로 가리키고 편집 때 파일 값을 같이 고치기: 고치는 곳을 하나라도 빠뜨리면 다시 어긋난다.
- 서버가 id로 바꿔 응답: 서버 계약이 바뀌고, id를 만든 쪽이 아닌 곳이 id를 다룬다.
- 지웠다 같은 이름으로 추가하면 원래 파일 복원: 되돌리기 기능이 따로 필요한데, 미분류에서 다시 고르면 충분하다.
