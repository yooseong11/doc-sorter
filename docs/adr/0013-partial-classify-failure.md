# 0013. 분류 부분 실패와 파일 상태 모델

## 결정
파일마다 상태(대기 → 읽는 중 → 분류 중 → 분류됨/실패)를 두고 재시도는 `실패`인 파일만 한다. 상태는 파일 객체 하나에 모아 저장 상태와 같이 쓴다.

## 이유
전체 재분류는 사용자가 확인 화면에서 고친 카테고리를 날리고(0004) API 비용이 배로 든다. 상태를 한 곳에 모으면 화면은 목록 하나만 그리면 된다(0011).

## 버린 대안
- 전체 재분류: 고친 결과가 사라지고 비용이 배로 든다.
- 첫 실패에서 전체 중단: 1개 실패로 나머지를 보지 못한다.
- 자동 재시도 N회: 보류. 실패 사유를 보여주는 쪽이 먼저다.
