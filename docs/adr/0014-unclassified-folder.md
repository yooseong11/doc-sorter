# 0014. 미분류 파일도 하위 폴더에 저장

## 결정
미분류 파일은 최상위에 두지 않고 카테고리와 똑같이 `미분류` 폴더를 만들어 그 안에 저장한다.

## 이유
카테고리 이름이 곧 폴더라는 규칙(0003)을 예외 없이 지키면 저장 경로 계산이 한 줄로 끝나고, 사람이 확인해야 할 파일이 한곳에 모여 원래 최상위에 있던 파일과 섞이지 않는다.

## 버린 대안
- 최상위에 그냥 두기: 기존 파일과 섞여 무엇이 이번에 들어온 미분류인지 구분되지 않는다.
- `_확인필요` 같은 별도 이름: 화면의 묶음 이름(미분류)과 폴더 이름이 달라 기록표(0006)와 대조하기 어렵다.
