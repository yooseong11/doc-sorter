# 0008. 서버로는 앞부분 텍스트만 보낸다

- 상태: 채택
- 날짜: 2026-09-17

## 결정
- 파일은 브라우저에만 둔다.
- 분류에 필요한 앞부분 텍스트만 서버(Vercel Functions)로 보낸다.

## 이유
- 경영지원 문서(계약서, 급여·근태 서류)는 민감하다. 서버에 데이터를 저장하기 시작하면 보안에 신경 쓸 부분과 개발 비용이 함께 늘어난다.
- 서버(Vercel Functions)는 API 키를 숨기고 LLM을 호출하는 역할만 한다.
- 분류는 첫 페이지 상단의 제목만 보여도 대부분 가능하다("전자세금계산서", "연차 신청서", "용역 계약서"). 앞부분만 보내면 비용과 외부 전송량이 함께 줄어든다.
- 앞부분 텍스트는 OpenAI로 전송된다. 보안의 핵심은 앱 형태(웹·exe)가 아니라 모델 위치다. 나중에 Azure OpenAI나 로컬 모델로 바꿀 수 있도록 호출 어댑터를 하나로 둔다.

## 버린 대안
- 파일 전체를 서버로 업로드: 파일이 외부로 나가고, 저장하지 않는다는 원칙을 지키기 어렵다.
- 이미지를 멀티모달 LLM에 직접 전송: 계약서 이미지가 외부로 나가는 보안 문제가 크고 비용도 높다.
- 전체 텍스트 전송: 분류에는 앞부분이면 충분한데 비용과 전송량만 늘어난다.
