# 0008. 서버로는 앞부분 텍스트만 보낸다

## 결정
파일은 브라우저에만 두고, 분류에 필요한 앞부분 텍스트만 서버(Vercel Functions)로 보낸다.

## 이유
경영지원 문서는 민감해서 서버에 저장하면 보안 부담과 비용이 는다. 분류는 첫 페이지 제목만 봐도 대부분 되고, 모델을 바꿀 수 있게 호출 어댑터는 하나로 둔다.

## 버린 대안
- 파일 전체 업로드: 파일이 외부로 나가고 저장하지 않는다는 원칙을 지키기 어렵다.
- 이미지를 멀티모달 LLM에 전송: 보안 위험과 비용이 크다.
- 전체 텍스트 전송: 비용과 전송량만 는다.
