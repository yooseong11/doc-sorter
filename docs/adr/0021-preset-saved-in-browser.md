# 0021. 편집한 카테고리 프리셋은 브라우저에 저장한다

## 결정
프리셋을 idb-keyval에 이름과 설명만 저장하고, 입력이 멈춘 뒤에 쓴다. 저장값이 계약 스키마에 맞지 않으면 버리고 기본값으로 시작한다.

## 이유
새로고침마다 카테고리를 다시 고치게 하면 편집 기능이 쓸모없어지고, 서버는 무상태로 두기로 했으므로(0019) 남길 곳은 브라우저뿐이다.

## 버린 대안
- 저장하지 않고 런타임 상태로만 두기: 새로고침하면 편집한 프리셋이 매번 날아간다.
- localStorage: 폴더 핸들을 이미 idb에 두고 있어(0003) 저장소가 둘로 갈린다.
- 입력할 때마다 저장: 타이핑 한 글자마다 디스크에 쓴다.
