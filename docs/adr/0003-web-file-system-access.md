# 0003. 웹 + File System Access API로 폴더 저장

## 결정
웹앱에서 최상위 폴더를 한 번 고르고 핸들을 IndexedDB(idb-keyval)에 기억한다. 카테고리 이름이 곧 하위 폴더이며, 비슷한 기존 폴더가 있으면 처음에 매핑한다.

## 이유
경로를 고정하면 폴더가 바뀔 때마다 재배포해야 하고, Vercel 서버는 회사 내부 파일 서버에 닿지 못한다. 브라우저가 사용자 PC에 직접 쓰면 설치·업데이트도 없다.

## 버린 대안
- exe 설치형: 재배포·자동 업데이트·코드 서명·IT 승인 부담이 1인 개발에 크다. 브라우저가 막히면 그때 Tauri로 감싼다.
- 관리자 경로 설정, 연도 폴더: 보류.
