# 0012. 폴더 선택 API 미지원 브라우저

## 결정
`'showDirectoryPicker' in window`로 기능을 확인하고, 없으면 첫 화면에서 안내만 하며 업로드 버튼도 막는다. zip 다운로드 대체 경로는 R1에서 만들지 않는다.

## 이유
업무 PC는 대부분 크롬·엣지다(0001). 분류까지 되고 저장에서 막히면 AI 비용만 쓴다. 이름이 아니라 기능으로 판단해야 사파리가 지원하는 날 코드를 고치지 않고 열린다.

## 버린 대안
- zip 다운로드: 사용자가 압축을 풀고 손으로 병합하게 되어 이 앱이 하는 일을 돌려준다. R3로 보류.
- User-Agent 분기: 브라우저가 이름을 바꾸면 따라가야 한다.
- 안내 없이 두기: 사용자가 원인을 알 수 없다.
