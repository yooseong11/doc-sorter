# 0002. 카테고리 구성

- 상태: 채택
- 날짜: 2026-09-17

## 맥락
분류 기준이 되는 카테고리가 필요하다.

## 결정
- 기본 카테고리: 비용 증빙, 근태, 복지 신청, 계약서, 미분류(사람 확인)
- 사용자 추가: 이름 + 설명 한 줄
- 확신이 없는 문서는 미분류로 보내 사람이 확인한다.

## 이유
- 범용으로 만들기보다 정해진 카테고리를 제공하는 편이 빠르게 만들 수 있다.
- 사용자가 무엇을 해야 할지 헷갈리지 않는다.
- 다른 팀이 쓰게 되면 카테고리 프리셋만 바꿔서 주면 된다. ([0001](0001-target-user-and-flow.md)의 "엔진 공통 + 카테고리 프리셋")
- 확신이 없는 문서를 미분류로 보내는 이유: [0001](0001-target-user-and-flow.md)의 "확인" 단계와 같다. AI가 틀릴 수 있고, 문서가 다른 곳으로 잘못 넘어가면 큰일이 난다.

## 버린 대안
- AI가 카테고리를 전부 만들기: 위험하다고 판단했다.
- 사용자가 카테고리를 처음부터 만들게 하기(범용): 프로젝트 범위가 커져 빠른 시일 내에 만들기 어렵고, 사용자가 어떻게 해야 할지 헷갈릴 수 있다.

## 결과
설명 한 줄은 AI 분류 프롬프트에 함께 들어간다.
