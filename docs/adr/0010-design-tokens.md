# 0010. 전역 디자인 토큰(CSS 변수)

## 결정
색·글꼴·간격·모서리·그림자는 `src/styles/tokens.css`의 CSS 변수로만 정의하고 컴포넌트는 `var()`로 쓴다. px는 4px 단위, radius는 2px 단위, font-size는 짝수, 홀수 px는 쓰지 않는다.

## 이유
Tailwind를 쓰기엔 프로젝트가 작고, CSS를 자유롭게 쓰면 같은 값이 흩어져 수정이 어렵다. CSS 변수는 브라우저 기본 기능이라 라이브러리·설정이 없다(0009).

## 버린 대안
- Tailwind: 도입 부담에 비해 얻는 것이 적다.
- 토큰 없이 자유 작성: 값이 흩어져 나중에 고치기 힘들다.
- px 규칙을 stylelint·테스트로 검사: 토큰 파일 한 곳만 보면 되어 필요 없다.
