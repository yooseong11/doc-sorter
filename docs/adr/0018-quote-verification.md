# 0018. 근거 인용문이 원문에 있는지 확인하고, 없으면 비운다

## 결정
공백을 모두 지우고 NFC로 맞춘 뒤 인용문이 보낸 원문에 들어 있는지 확인한다. 없으면 인용문만 비우고 카테고리는 살린다. 원문을 넘기지 않은 호출도 비운다.

## 이유
0015는 "원문 문장 그대로"를 전제했지만 모델은 지어낼 수 있고, 지어낸 문장을 근거로 보여주면 사용자가 오분류를 잡아내지 못한다.

## 버린 대안
- 공백까지 그대로 비교: PDF 추출이 글자 조각을 공백으로 이어 붙여서 멀쩡한 인용문도 전부 탈락한다.
- 인용문이 없으면 미분류 처리: 카테고리는 맞는데 인용만 틀린 경우까지 되돌려 손볼 일이 늘어난다.
- 부분 일치·유사도 비교: 기준을 정할 근거가 없고, 지어낸 문장도 낱말이 겹치면 통과한다.
