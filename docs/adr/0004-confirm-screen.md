# 0004. 확인 화면

## 결정
한 줄에 파일명·카테고리·근거 한 줄을 보이고 ⚠️만 펼친다. 클릭하면 미리보기. 카테고리별로 묶어 개수를 표시하고, 행마다 드롭다운으로 바꾸면 그 묶음으로 이동한다.

## 이유
파일명만으로는 판단 근거가 없고 매번 열면 느려서 확인을 건너뛴다. 근거는 원문 발췌라 파일을 열지 않아도 왜 여기로 갔는지 보인다.

## 버린 대안
- 파일명만 표시: 판단할 근거가 없다.
- 전부 열어서 확인: 느려서 담당자가 건너뛴다.
- 드래그앤드롭 보드: 보류. 칸이 좁아 근거가 잘리고 카테고리가 늘면 가로로 넘친다.
