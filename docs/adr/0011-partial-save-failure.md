# 0011. 저장 부분 실패와 기록 시점

## 결정
이미 저장된 파일은 되돌리지 않는다. 파일 하나를 쓸 때마다 기록표에 한 줄씩 이어 쓰고, 실패해도 반복문은 끝까지 돌며 재시도는 실패한 파일만 한다.

## 이유
되돌리기는 삭제 권한이 필요해 권한 회수 때 작동하지 않고, 남의 회사 폴더에서 파일을 지우는 위험이 크다. 파일 단위로 기록하면 기록표와 폴더가 항상 일치한다(0006).

## 버린 대안
- 롤백: 가장 흔한 실패 원인인 권한 회수 상황에서 작동하지 않는다.
- 배치 완료 후 일괄 기록: 중단되면 폴더에만 있고 기록표에 없는 파일이 생긴다.
- 실패 시 즉시 중단: 나머지가 되는지 알 수 없다.
