# 0020. 카테고리 설명은 검증하지 않고 그대로 프롬프트에 넣는다

## 결정
사용자가 쓴 카테고리 설명은 비어 있어도 받고 내용도 거르지 않는다. 비었을 때 화면에 경고만 띄우고 분류는 막지 않는다.

## 이유
설명은 분류 품질을 좌우할 뿐 앱을 깨뜨리지 않으며, 프리셋을 쓰는 사람과 결과를 받는 사람이 같으므로(0001) 잘못 쓴 결과는 그 사람이 확인 화면에서 바로 본다(0004).

## 버린 대안
- 설명을 필수로 강제: 이름만으로 충분한 카테고리에도 빈칸을 못 넘어가게 막아 편집을 방해한다.
- 설명에서 지시문을 걸러내기: 본문과 달리 설명은 사용자가 스스로 쓰는 값이라 막을 대상이 없고, 걸러낼 문구 목록만 늘어난다.
