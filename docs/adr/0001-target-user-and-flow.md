# 0001. 대상 사용자와 기본 흐름

- 상태: 채택
- 날짜: 2026-09-17

## 맥락
소규모 회사 경영지원 담당자에게 여러 종류의 문서가 한 번에 들어온다.

## 결정
- 주 사용자: 소규모 회사 경영지원 담당자
- 구조: 엔진 공통 + 카테고리 프리셋
- 흐름: 받는다 → 나눈다 → 확인 → 폴더 저장 → 기록

## 이유
- 여러 직무가 문서를 종류별로 받지만, 소규모 회사 경영지원팀이 복지·세무·근태 등 가장 여러 종류의 파일을 받는다고 판단했다.
- 흐름에 "확인" 단계를 넣은 이유: AI가 틀릴 수 있다. 경영지원 문서는 다른 곳으로 잘못 넘어가면 큰일이 나므로 사람이 저장 전에 확인한다.

## 버린 대안
아래 사용자들도 섞여 들어오는 문서가 있어 후보로 검토했다.

| 사용자 | 섞여 들어오는 문서 |
|---|---|
| 경영지원 담당자 (채택) | 세금계산서, 근태, 복지, 계약서 |
| 세무사 사무소 직원 | 고객사가 보낸 영수증, 계산서, 급여대장 |
| 영업관리 담당자 | 견적서, 발주서, 거래명세서 |
| 연구실·학과 행정 | 연구비 증빙, 출장 보고서, 회의비 |
| 법무·계약 담당 | 계약서, NDA, 합의서 |

- 연구원, 회계 담당자도 문서를 종류별로 받지만, 경영지원팀보다 받는 문서 종류가 적다고 보았다.

## 결과
다른 직무용 프리셋은 엔진을 건드리지 않고 추가한다.
