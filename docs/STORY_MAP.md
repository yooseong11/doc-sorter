# 스토리 맵

## 사용자
- 정호연
- 경영지원팀
- 복지, 휴무, 계약서, 정부서류, 세금 영수증 여러 가지가 한 번에 들어와서 처리하기 힘들어함

## 스토리 라인

### 1. 보고서 업로드
- 파일 여러 개 한 번에 업로드
- 파일 형태 여러가지 지원 (hwpx, pdf(텍스트), docx)

### 2. 보고서 분류
- AI로 키워드 인식 (파일명, 내용)
- 미리 정해둔 카테고리대로 분류, 없는 카테고리는 미분류로

### 3. 분리된 보고서 확인하기
- 미분류 카테고리 수정하기
- 카테고리 추가하기
- 파일의 카테고리 바꾸기 (드롭다운)
- 카테고리별로 묶어서 소속 보기
- 파일명에 따른 인용문 보이기

### 4. 보고서 폴더 별로 이동
- 최상위 폴더를 정하고 카테고리를 폴더명으로 정해진 폴더에 다운로드
- 기존 폴더가 같은 이름으로 있는 경우 해당 폴더에 다운로드
- 기존 파일명과 동일한 경우 _2, _3 붙이기
- 분류기록표_YYMMDD.CSV 만들기

## 릴리스 맵

가로는 사용자가 거치는 활동, 세로는 릴리스. 위 칸이 먼저다.

| | 1 받는다 | 2 나눈다 | 3 확인한다 | 4 저장한다 | 5 기록한다 |
|---|---|---|---|---|---|
| **R1 뼈대**<br>한 번은 끝까지 간다 | 파일 선택 버튼으로 여러 개 업로드 · pdf(텍스트)·docx 텍스트 추출 | 고정 카테고리로 AI 분류 · 해당 없으면 미분류 | 파일 목록 + 드롭다운으로 카테고리 바꾸기 | 최상위 폴더 선택 · 카테고리명 폴더에 저장(있으면 그 폴더 재사용) | 분류기록표_YYMMDD.csv |
| **R2 쓸 만하게**<br>실제 업무에 쓴다 | hwpx 텍스트 추출 | 분류 근거 인용문 같이 받기 | 카테고리별로 묶어서 보기 · 파일별 근거 인용문 표시 | 같은 파일명이면 `_2`, `_3` (ADR 0005) | — |
| **R3 내 회사에 맞추기**<br>남의 회사도 쓴다 | 드롭존(끌어다 놓기) | 편집한 프리셋으로 분류 · 근거 인용문이 원문에 있는지 확인(없으면 비움) | 카테고리 추가·이름 변경 · 프리셋 저장(idb-keyval) | — | — |

### 릴리스별 완료 조건

- **R1** — pdf 3개, docx 2개를 넣고 바탕화면 폴더를 골랐을 때, 카테고리 폴더가 만들어지고 파일 5개와 csv 1개가 들어가 있다.
- **R2** — 같은 이름의 파일이 섞여 있어도 덮어쓰이지 않고, 왜 그 카테고리인지 화면에서 읽을 수 있다.
- **R3** — 카테고리 목록을 바꾸고 새로고침해도 유지된다.

### 진행 현황

- ✅ R1 뼈대 — 완료(2026-09-18)
- **R2 / R3** — 시작 전.

### 이 맵에 없는 것 (보류)

- OCR (이미지 pdf), 구형 `.hwp` 추출, AI 파일명 제안, exe 배포, 연도 폴더
- 확인 화면의 보드형 드래그앤드롭 — 드롭다운으로 대체 (ADR 0004)
