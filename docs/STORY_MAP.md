# 스토리 맵

## 사용자
- 정호연
- 경영지원팀
- 복지, 휴무, 계약서, 정부서류, 세금 영수증 여러 가지가 한 번에 들어와서 처리하기 힘들어함

## 스토리 라인

### 1. 보고서 업로드
- 파일 여러 개 한 번에 업로드
- 파일 형태 여러가지 지원 (hwpx, pdf(텍스트), docx)

### 2. 보고서 분류
- AI로 키워드 인식 (파일명, 내용)
- 미리 정해둔 카테고리대로 분류, 없는 카테고리는 미분류로

### 3. 분리된 보고서 확인하기
- 미분류 카테고리 수정하기
- 카테고리 추가하기
- 파일의 카테고리 바꾸기 (드롭다운)
- 카테고리별로 묶어서 소속 보기
- 파일명에 따른 인용문 보이기

### 4. 보고서 폴더 별로 이동
- 최상위 폴더를 정하고 카테고리를 폴더명으로 정해진 폴더에 다운로드
- 기존 폴더가 같은 이름으로 있는 경우 해당 폴더에 다운로드
- 기존 파일명과 동일한 경우 _2, _3 붙이기
- 분류기록표_YYMMDD.CSV 만들기

## 릴리스 맵

가로는 사용자가 거치는 활동, 세로는 릴리스. 위 칸이 먼저다.

| | 1 받는다 | 2 나눈다 | 3 확인한다 | 4 저장한다 | 5 기록한다 |
|---|---|---|---|---|---|
| **R1 뼈대** | 파일 선택 버튼으로 여러 개 업로드 · pdf(텍스트)·docx 텍스트 추출 | 고정 카테고리로 AI 분류 · 해당 없으면 미분류 | 파일 목록 + 드롭다운으로 카테고리 바꾸기 | 최상위 폴더 선택 · 카테고리명 폴더에 저장(있으면 그 폴더 재사용) | 분류기록표_YYMMDD.csv |
